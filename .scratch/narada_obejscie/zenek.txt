# Issue tracker: Local Markdown

Issues and specs (you may know a spec as a PRD) for this repo live as markdown files in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The spec is `.scratch/<feature-slug>/spec.md`
- Implementation issues are one file per ticket at `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, numbered from `01` — never a single combined tickets file
- Triage state is recorded as a `Status:` line near the top of each issue file (see `triage-labels.md` for the role strings)
- Comments and conversation history append to the bottom of the file under a `## Comments` heading

## When a skill says "publish to the issue tracker"

Create a new file under `.scratch/<feature-slug>/` (creating the directory if needed).

## When a skill says "fetch the relevant ticket"

Read the file at the referenced path. The user will normally pass the path or the issue number directly.

## Wayfinding operations

Used by `/wayfinder`. The **map** is a file with one **child** file per ticket.

- **Map**: `.scratch/<effort>/map.md` — the Notes / Decisions-so-far / Fog body.
- **Child ticket**: `.scratch/<effort>/issues/NN-<slug>.md`, numbered from `01`, with the question in the body. A `Type:` line records the ticket type (`research`/`prototype`/`grilling`/`task`); a `Status:` line records `claimed`/`resolved`.
- **Blocking**: a `Blocked by: NN, NN` line near the top. A ticket is unblocked when every file it lists is `resolved`.
- **Frontier**: scan `.scratch/<effort>/issues/` for files that are open, unblocked, and unclaimed; first by number wins.
- **Claim**: set `Status: claimed` and save before any work.
- **Resolve**: append the answer under an `## Answer` heading, set `Status: resolved`, then append a context pointer (gist + link) to the map's Decisions-so-far in `map.md`.

## Uwaga dla tego repozytorium (rod-ai-studio)

Wybrano wariant **local markdown**, mimo że `origin` wskazuje na GitHub
(`git@github.com:makol100/rod-ai-studio.git`). Powód: `gh` CLI nie jest
zainstalowany na tym serwerze, a praca nigdy nie była prowadzona przez GitHub
Issues — historia decyzji i lekcji żyje w plikach markdown i commitach.

Rozdział ról, żeby nie mieszać dwóch różnych rzeczy:

- `.scratch/<feature>/` — **bieżąca robota**: specyfikacje i tickety opisane wyżej.
- `wiedza/` — **pamięć trwała fabryki**: decyzje (`DECYZJE_*.md`), lekcje
  (`LEKCJA_*.md`), analizy i przekazania. Tego katalogu skille nie traktują jak
  issue trackera i nie zapisują tam ticketów.

def zapisz_manifest(katalog: str, plik_zadania: str, kto: list, wykonanie: bool) -> str:
    """Manifest zadania — DLA HENIA, na jego zadanie z 4.08.2026.

    Dekret Tomasza: "Hans jest narzedziem Henka i tylko Henka (...) moze i musi przeanalizowac

    Zapis jednorazowy, nie nadpisuje istniejacego (dekret 2.08: nikt niczego nie usuwa).
    """
    os.makedirs(katalog, exist_ok=True)
    sciezka = os.path.join(katalog, "manifest.json")
    if os.path.exists(sciezka):
        return sciezka

    zrodla = []
    for korzen, _, pliki in os.walk(os.path.join(REPO, "wiedza")):
        for nazwa in sorted(pliki):
            if not nazwa.endswith(".md"):
                continue
            pelna = os.path.join(korzen, nazwa)
            try:

func (c *Cloud) Request(baseURL, apiURL, params string, headers map[string]string) ([]byte, error) {
	form := url.Values{"data": {params}}

	nonce := genNonce()
	signedNonce := genSignedNonce(c.ssecurity, nonce)

	form.Set("rc4_hash__", genSignature64("POST", apiURL, form, signedNonce))

		}
		v[0] = base64.StdEncoding.EncodeToString(ciphertext)
	}

	// 3. add signature for encrypted data and hash params
	form.Set("signature", genSignature64("POST", apiURL, form, signedNonce))

	// 4. add nonce
	form.Set("_nonce", base64.StdEncoding.EncodeToString(nonce))

	req, err := http.NewRequest("POST", baseURL+apiURL, strings.NewReader(form.Encode()))

		return nil, err
	}

	}

		return nil, err
	}

func readLoginResponse(rc io.ReadCloser, v any) ([]byte, error) {
	defer rc.Close()

	if err != nil {
		return nil, err
	}

func genNonce() []byte {
	ts := time.Now().Unix() / 60

	nonce := make([]byte, 12)
	_, _ = rand.Read(nonce[:8])
	binary.BigEndian.PutUint32(nonce[8:], uint32(ts))
	return nonce
}

func genSignedNonce(ssecurity, nonce []byte) []byte {
	hasher := sha256.New()
	hasher.Write(ssecurity)
	hasher.Write(nonce)
	return hasher.Sum(nil)
}

func crypt(key, plaintext []byte) ([]byte, error) {
	cipher, err := rc4.NewCipher(key)
	if err != nil {
		return nil, err
	}

	tmp := make([]byte, 1024)
	cipher.XORKeyStream(tmp, tmp)

	ciphertext := make([]byte, len(plaintext))
	cipher.XORKeyStream(ciphertext, plaintext)

	return ciphertext, nil
}

func genSignature64(method, path string, values url.Values, signedNonce []byte) string {
	s := method + "&" + path + "&data=" + values.Get("data")
	if values.Has("rc4_hash__") {
		s += "&rc4_hash__=" + values.Get("rc4_hash__")
	}
	s += "&" + base64.StdEncoding.EncodeToString(signedNonce)

	hasher := sha1.New()
	hasher.Write([]byte(s))
	signature := hasher.Sum(nil)

	return base64.StdEncoding.EncodeToString(signature)
}

    90	func getCameraURL(url *url.URL) (string, error) {
    91		model := url.Query().Get("model")
    92	
    93		// It is not known which models need to be awakened.
    94		// Probably all the doorbells and all the battery cameras.
    95		if strings.Contains(model, ".cateye.") {
    96			_ = wakeUpCamera(url)
    97		}
    98	
    99		// The getMissURL request has a fallback to getP2PURL.
   100		// But for known models we can save one request to the cloud.
   101		if xiaomi.IsLegacy(model) {
   102			return getLegacyURL(url)
   103		}
   104		return getMissURL(url)
   105	}

   108		query := url.Query()

   110		clientPublic, clientPrivate, err := crypto.GenerateKey()
   111		if err != nil {

   149	func getMissURL(url *url.URL) (string, error) {
   150		clientPublic, clientPrivate, err := crypto.GenerateKey()
   151		if err != nil {
   152			return "", err
   153		}
   154	
   155		query := url.Query()
   156		params := fmt.Sprintf(
   157			`{"app_pubkey":"%x","did":"%s","support_vendors":"TUTK_CS2_MTP"}`,
   158			clientPublic, query.Get("did"),
   159		)
   160	
   161		res, err := cloudUserRequest(url.User, "/v2/device/miss_get_vendor", params)
   162		if err != nil {
   163			if strings.Contains(err.Error(), "no available vendor support") {
   164				return getLegacyURL(url)
   165			}
   166			return "", err
   167		}
   168	
   169		var v struct {
   170			Vendor struct {
   171				ID     byte `json:"vendor"`
   172				Params struct {
   173					UID string `json:"p2p_id"`
   174				} `json:"vendor_params"`
   175			} `json:"vendor"`
   176			PublicKey string `json:"public_key"`
   177			Sign      string `json:"sign"`
   178		}
   179		if err = json.Unmarshal(res, &v); err != nil {
   180			return "", err
   181		}
   182	
   183		query.Set("client_public", hex.EncodeToString(clientPublic))
   184		query.Set("client_private", hex.EncodeToString(clientPrivate))
   185		query.Set("device_public", v.PublicKey)
   186		query.Set("sign", v.Sign)
   187		query.Set("vendor", getVendorName(v.Vendor.ID))
   188	
   189		if v.Vendor.ID == 1 {
   190			query.Set("uid", v.Vendor.Params.UID)
   191		}
   192	
   193		url.RawQuery = query.Encode()
   194		return url.String(), nil
   195	}

   227	func apiDeviceList(w http.ResponseWriter, r *http.Request) {
   228		query := r.URL.Query()
   229	
   230		user := query.Get("id")
   231		if user == "" {
   232			cloudsMu.Lock()
   233			users := make([]string, 0, len(tokens))
   234			for s := range tokens {
   235				users = append(users, s)
   236			}
   237			cloudsMu.Unlock()
   238	
   239			api.ResponseJSON(w, users)
   240			return
   241		}
   242	
   243		err := func() error {
   244			region := query.Get("region")
   245			res, err := cloudRequest(user, region, "/v2/home/device_list_page", "{}")
   246			if err != nil {
   247				return err
   248			}
   249			var v struct {
   250				List []*Device `json:"list"`
   251			}
   252	
   253			if err = json.Unmarshal(res, &v); err != nil {
   254				return err
   255			}
   256	
   257			var items []*api.Source
   258	
   259			for _, device := range v.List {
   260				if !strings.Contains(device.Model, ".camera.") && !strings.Contains(device.Model, ".cateye.") {
   261					continue
   262				}
   263				items = append(items, &api.Source{
   264					Name: device.Name,
   265					Info: fmt.Sprintf("ip: %s, mac: %s", device.IP, device.MAC),
   266					URL:  fmt.Sprintf("xiaomi://%s:%s@%s?did=%s&model=%s", user, region, device.IP, device.Did, device.Model),
   267				})
   268			}
   269	
   270			api.ResponseSources(w, items)
   271			return nil
   272		}()
   273	
   274		if err != nil {
   275			http.Error(w, err.Error(), http.StatusInternalServerError)
   276		}
   277	}

passToken=V1:...

**Droga B:** go2rtc 1.9.14 nie przyjmuje `ssecurity` ani `serviceToken` w konfiguracji. Konfiguracja `xiaomi` jest mapą `userID → string`, a jedyną ścieżką startową jest `LoginWithToken(userID, passToken)`. Wstrzyknięcie kompletnej sesji wymagałoby zmiany kodu.

**Droga C:** SMS nie jest wybierany parametrem. Xiaomi zwraca flagę metody; kod mapuje flagę `4 → Phone`, `8 → Email`. Jeśli Xiaomi zwróciło flagę email, API go2rtc nie ma przełącznika wymuszającego telefon. [cloud.go](https://github.com/AlexxIT/go2rtc/blob/v1.9.14/pkg/xiaomi/cloud.go)

Co więcej, `apiAuth` go2rtc w ogóle nie odczytuje pola `server`. Zmiana regionu nie powinna ominąć limitu wysyłki kodów.
