1. Każdy fragment powinien zawierać ruch albo czytelną zmianę sytuacji już od pierwszej sekundy.

### 2.3. Normalizacja pięciu źródeł

Domyślny wariant: **scale + pad**.

Powody:

- zachowuje cały obraz;
- nie ucina góry ani dołu;
- nie rozciąga sylwetek;
- stabilizuje wszystkie źródła do 1080×1920 i 30 fps;
- dla klipów 1072×1920 margines będzie minimalny;
- dla węższych klipów 824×1920 pojawią się wyraźniejsze marginesy boczne.

Filtry:

- `scale=...:force_original_aspect_ratio=decrease` — dopasowanie bez deformacji;
- `pad=1080:1920` — uzupełnienie płótna;
- `setsar=1` — kwadratowe piksele;
- `fps=30` — stabilne 30 fps;
- `format=yuv420p` — kompatybilność publikacyjna.

```bash
ffmpeg -y -i "$SRC/20260722_093926.mp4" \
  -map 0:v:0 -an \
  -vf "scale=1080:1920:force_original_aspect_ratio=decrease:flags=lanczos,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:black,setsar=1,fps=30,format=yuv420p" \
  -c:v libx264 -preset medium -crf 18 \
  -movflags +faststart \
  "$WRK/n01.mp4"

ffmpeg -y -i "$SRC/20260722_094249.mp4" \

### 2.9. Finalne połączenie

Czołówka i korpus mają identyczne parametry techniczne. Łączymy je filtrem `concat` i wykonujemy finalny encode:

```bash
ffmpeg -y \
  -i "$WRK/title.mp4" \
  -i "$WRK/news_body.mp4" \
  -filter_complex "\
    [0:v]setpts=PTS-STARTPTS[v0];\
    [0:a]asetpts=PTS-STARTPTS[a0];\
    [1:v]setpts=PTS-STARTPTS[v1];\
    [1:a]asetpts=PTS-STARTPTS[a1];\

  -map "[v]" \
  -map "[a]" \
  -c:v libx264 \
  -preset medium \
  -crf 18 \
  -profile:v high \
  -level 4.2 \
  -pix_fmt yuv420p \
  -r 30 \
  -c:a aac \
  -b:a 192k \
  -ar 48000 \
  -movflags +faststart \

```

- `scale=...:force_original_aspect_ratio=decrease` — dopasowanie bez deformacji;

Ten wariant można analogicznie zastosować do `n02`.

Crop nie jest wariantem domyślnym. Przy źródle 824×1920 dopasowanie przez powiększenie do szerokości 1080 wymagałoby znacznego ucięcia góry i dołu.

ffmpeg -y \

### 2.5. TTS ElevenLabs

Ustawienia:

- głos: **Daniel**;
- model: `eleven_multilingual_v2`;
- tekst: około 60–75 s;
- „ROD” zapisać pełnymi słowami;
- wygenerować jeden finalny plik po zatwierdzeniu tekstu.

W tekście TTS zamiast:

```text
ROD
```

użyć:

```text
Rodzinnego Ogrodu Działkowego
```

albo odpowiedniej formy gramatycznej, np.:

```text
na terenie Rodzinnego Ogrodu Działkowego
```

Finalny TTS zapisać jako:

```text
$WRK/stanislaw_tts_raw.wav
```

Normalizacja:

```bash
ffmpeg -y \
  -i "$WRK/stanislaw_tts_raw.wav" \
  -af "loudnorm=I=-16:TP=-1.5:LRA=7,apad=pad_dur=0.4" \
  -ar 48000 \
  -ac 2 \
  "$WRK/stanislaw_tts.wav"
```

Uwaga: powyższy `loudnorm` jest wygodny dla proxy. Dla maksymalnie dokładnego poziomu mastera można wykonać dwupassową normalizację `loudnorm`, wykorzystując pomiary z pierwszego przebiegu.

### 2.6. Generacja awatara Kling

Ustawienia:

- model: **Kling STANDARD**;
- koszt wskazany w kanonie: **$2.27**;
- liczba prób: **1**;
- karta: `karta_stanislaw_CANON.png`;
- format po generacji: około 1072×1920;
- stały prompt zawierający: `calm presentation, eye contact`;
- ruch spokojny, prezenter wiadomości;
- bez szerokiej gestykulacji;
- długość obejmująca cały finalny TTS i około 0,4 s zapasu po ostatnim zdaniu.

Nie uruchamiać Kling przed:

- zatwierdzeniem tekstu;
- odsłuchem TTS;
- sprawdzeniem wymowy;
- potwierdzeniem finalnej długości;
- sprawdzeniem właściwej karty;
- potwierdzeniem modelu STANDARD i kosztu.

Po pobraniu awatara:

```bash
ffmpeg -y \
  -i "$WRK/kling_stanislaw.mp4" \
  -i "$WRK/stanislaw_tts.wav" \
  -map 0:v:0 \
  -map 1:a:0 \
  -shortest \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase:flags=lanczos,crop=1080:1920,setsar=1,fps=30,format=yuv420p" \
  -c:v libx264 -preset medium -crf 18 \
  -c:a aac -b:a 192k -ar 48000 \
  "$WRK/avatar_master.mp4"
```

Crop awatara jest dopuszczalny, ponieważ różnica między 1072×1920 a 1080×1920 jest minimalna.

#### Ważna kontrola synchronizacji

Jeżeli Kling wygeneruje obraz zsynchronizowany ze swoją kopią audio, podłożenie ponownie WAV ElevenLabs powinno być bezpieczne tylko wtedy, gdy długość i timing są identyczne.

Sprawdzić synchronizację:

- na pierwszym zdaniu;
- w połowie materiału;
- na „Do usłyszenia przy płocie”.

Jeżeli występuje dryf:

- zachować oryginalne audio z Kling;
- albo ustalić dokładne przesunięcie audio;
- nie rozciągać obrazu bez dokładnego pomiaru.

| b06 | 35,6–41,1 | 38,8–44,3 |
| b07 | 41,1–47,1 | 44,3–50,3 |

### 2.9. Finalne połączenie

Czołówka i korpus mają identyczne parametry techniczne. Łączymy je filtrem `concat` i wykonujemy finalny encode:

```bash
ffmpeg -y \
  -i "$WRK/title.mp4" \
  -i "$WRK/news_body.mp4" \
  -filter_complex "\
    [0:v]setpts=PTS-STARTPTS[v0];\
    [0:a]asetpts=PTS-STARTPTS[a0];\
    [1:v]setpts=PTS-STARTPTS[v1];\
    [1:a]asetpts=PTS-STARTPTS[a1];\
    [v0][a0][v1][a1]concat=n=2:v=1:a=1[v][a]" \
  -map "[v]" \
  -map "[a]" \
  -c:v libx264 \
  -preset medium \
  -crf 18 \
  -profile:v high \
  -level 4.2 \
  -pix_fmt yuv420p \
  -r 30 \
  -c:a aac \
  -b:a 192k \
  -ar 48000 \
  -movflags +faststart \
  "$OUT/WD_0001_teren_master.mp4"
```

Ustawienia robocze:

- proxy: `-preset veryfast -crf 23`;
- master: `-preset medium -crf 18`.

Nie wykonywać wielu kolejnych transkodowań mastera. Poprawki zatwierdzać na proxy, a finalny plik wyrenderować z najlepszych plików pośrednich.
