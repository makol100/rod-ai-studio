Oficjalne repo obsługuje Linux CPU i oferuje metody F0 `dio`, `harvest`, `pm` oraz RMVPE. [Repo RVC](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) | **TAK**, jeżeli potrzebna jest rzeczywiście inna tożsamość głosu i mamy gotowy model; **NIE** jako prosty efekt „duszonego” |
| **(b) Praat** | Pakiet systemowy `praat`; bez Pythona i modeli | **0,1–1 s** | `pitch floor` jest parametrem analizy, nie efektem. Jitter i shimmer Praat przede wszystkim mierzy; ich silne sztuczne dodawanie wymaga manipulacji PitchTier/IntensityTier i łatwo brzmi jak awaria syntezy. Formant shift oraz pitch range działają natywnie przez PSOLA. [Dokumentacja Change gender](https://praat.org/manual/Sound__Change_gender___.html), [analiza jitter/shimmer](https://praat.org/manual/Voice) | **TAK** — najlepsza lekka droga do kontrolowanego „ściśniętego/duszonego” charakteru |
| **(c) WORLD / SoundTouch / Rubber Band** | `pip install pyworld numpy scipy soundfile`; SoundTouch z APT; Rubber Band już jest | **WORLD 0,1–1 s**, SoundTouch/Rubber Band zwykle **<0,2 s** | WORLD daje bezpośredni dostęp do F0, obwiedni widmowej i aperiodyczności, ale po mocniejszych zmianach brzmi wokoderowo. PyWORLD wymaga próbkowania co najmniej 16 kHz. SoundTouch zmienia głównie tempo i pitch, nie pełną barwę/formanty; dla tego zadania nie daje istotnej przewagi nad posiadanym Rubber Band. [PyWORLD](https://pypi.org/project/pyworld/) | **TAK** dla prototypów WORLD; **NIE** dla SoundTouch jako zamiennika obecnego ffmpeg |
| **(d) so-vits-svc** | Najprościej `so-vits-svc-fork`, PyTorch CPU, HuBERT/ContentVec oraz zgodny checkpoint i konfiguracja | **około 15–60 s**, zależnie od CPU i modelu | Cięższe i bardziej kapryśne niż RVC, projekt bazowy jest zarchiwizowany i nastawiony głównie na śpiew. Trening praktycznie wymaga GPU; checkpointy między wersjami nie zawsze są zgodne. Fork deklaruje działający inference CPU, ale dla krótkiej mowy nie uzasadnia kosztu wdrożenia. [Fork i instalacja](https://github.com/voicepaw/so-vits-svc-fork), [projekt bazowy](https://github.com/svc-develop-team/so-vits-svc/tree/4.1-Stable) | **NIE** na tym VPS; rozważać dopiero z gotowym modelem, gdy RVC jakościowo zawiedzie |

Podane czasy są realistycznymi przedziałami, nie gwarantowanym benchmarkiem — nie znamy modelu CPU VPS. Praat/WORLD powinny działać znacznie szybciej od czasu rzeczywistego; dla RVC i so-vits-svc trzeba wykonać pomiar na docelowym procesorze.

Praat może zabrzmieć naturalniej od pojedynczych filtrów ffmpeg, ponieważ potrafi zmienić formanty i zakres F0 bez zmiany długości wypowiedzi. Nie zastąpi jednak modelu voice-conversion. Najlepszy wynik dają **małe** zmiany, np. formanty `0.93–0.97`, zakres pitch `0.70–0.85`, a następnie subtelny filtr przytłumiający w ffmpeg. Wartości skrajne powodują metaliczność.

Przykładowy skrypt `duszony.praat`:

```praat
form Obróbka głosu
    sentence Wejscie input.wav
    sentence Wyjscie output.wav
    positive Pitch_floor_Hz 70
    positive Pitch_ceiling_Hz 500
    positive Formant_shift 0.95
    positive Pitch_range 0.78
endform

Read from file: wejscie$
sound = selected("Sound")

# Pitch floor/ceiling sterują analizą F0.
To Pitch: 0.0, pitch_floor_Hz, pitch_ceiling_Hz
pitch = selected("Pitch")

selectObject: sound, pitch
# 0 Hz zachowuje medianę F0; czas pozostaje bez zmian.
Change gender: formant_shift, 0.0, pitch_range, 1.0

# Delikatne pulsowanie amplitudy imituje shimmer.
Formula: "self * (1 + 0.012 * sin(2*pi*7*x))"

Scale peak: 0.95
Save as WAV file: wyjscie$
```

Ten skrypt zachowuje słowa, czas i zasadniczy przebieg prozodii. Nie dodawałbym jawnego jitteru w pierwszej wersji: losowe zaburzanie okresów F0 częściej pogarsza naturalność niż buduje efekt „duszenia”. Jeśli jest potrzebna chrypka, bezpieczniej dodać ją bardzo subtelnie później jako składnik szumowy.

Uruchomienie:

```bash
praat --run duszony.praat input.wav output.wav 70 500 0.95 0.78
```

## NAJLEPSZA DROGA

**Praat z umiarkowanym przesunięciem formantów i zwężeniem zakresu F0, uzupełniony istniejącym łańcuchem ffmpeg, jest na tym VPS najszybszą, najstabilniejszą i najbardziej kontrolowalną drogą do naturalnego efektu „duszonego”.**

## KOMENDY instalacji dla najlepszej

```bash
sudo apt-get update
sudo apt-get install -y praat
praat --version
```

W minimalnym kontenerze bez repozytorium zawierającego Praat:

```bash
sudo apt-get update
sudo apt-get install -y wget ca-certificates libasound2 libgtk-3-0
wget -O /tmp/praat.tar.gz \
  https://github.com/praat/praat/releases/latest/download/praat6414_linux-intel64-barren.tar.gz
sudo mkdir -p /opt/praat
sudo tar -xzf /tmp/praat.tar.gz -C /opt/praat
sudo ln -s /opt/praat/praat /usr/local/bin/praat
praat --version
```

Adres drugiego wariantu zawiera numer wydania, więc przed automatyzacją należy sprawdzić aktualną nazwę artefaktu; instalacja z APT jest stabilniejsza.
