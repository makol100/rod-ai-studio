# NARADA: reżyseria ruchu żywego Pana Stanisława. Genek.
Ożywiamy kartę Pana Stanisława modelem klasy AI Avatar (obraz+audio -> cały mówiący człowiek, 40s powitania). Tomasz skrytykował poprzednią wersję: "chłop bez życia, zdjęcie ruszające ustami". Teraz będzie pełny ruch — ale to miecz obosieczny: avatar modele lubią przesadzać (teatralne machanie rękami, kiwanie się jak wańka-wstańka).
ZADANIE:
1. REŻYSERIA: opisz jak ma się ruszać Pan Stanisław podczas 40s powitania, żeby był ŻYWY ale DOSTOJNY (stary prezenter TVP przy herbacie): głowa, brwi, oczy/mruganie, dłonie (ma notes i szklankę w zasięgu!), tułów. Czego NIE wolno (lista zakazów).
2. PROMPT STERUJĄCY (ENG): jeśli model przyjmie tekstowy prompt zachowania — napisz zwięzły prompt (2-4 zdania ENG) opisujący ruch: warm dignified elderly TV presenter, subtle natural head movements, occasional gentle hand gesture, calm blinking, no exaggerated gestures... (dopracuj po swojemu, konkretnie).
3. PLAN B REŻYSERSKI: gdyby model przesadzał z ruchem — co poświęcić, co chronić (priorytet: tożsamość twarzy z kanonu? spokój? sync ust?).
Format: ## REŻYSERIA / ## PROMPT ENG / ## PLAN B. Zwięźle i konkretnie.
